# SurveyHUD

Android proof-of-concept for survey point navigation using the phone camera as an augmented heads-up display.

## V0.1 goals
- Rear-camera live view
- Import comma-delimited survey points in P,N,E,Z,D format
- Phone location and orientation
- Display nearby survey points over the camera view
- Select/highlight an active point
- Show bearing and distance to the active point

> Proof of concept only. Phone GPS/orientation and visual overlays are not survey measurements and must not replace the data collector/GNSS stakeout workflow.

## Roadmap
1. Camera + phone sensors + point-file import
2. Stable AR tracking
3. Carlson/rover live position integration
4. DXF/topographic linework overlay
5. AR-glasses display
